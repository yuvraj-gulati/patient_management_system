# Patient Management System

A full-stack web application developed using Angular, .NET Core, and MS SQL Server for efficient patient data management.

---

## Features

- User Authentication & Authorization
- Patient Record Management
- Dynamic Forms with Validation
- RESTful API Integration
- Interactive Dashboard
- Responsive UI Design
- Modular Architecture

---

## Tech Stack

### Frontend
- Angular
- TypeScript
- HTML
- CSS
- Bootstrap

### Backend
- .NET Core
- C#

### Database
- MS SQL Server
